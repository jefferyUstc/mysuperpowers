# Editorial policy

Standing decisions the user has made about articles in general. They hold for every article until the user changes them.

- Read this before proposing anything. A question this file answers is not asked again.
- When the user decides something that is about articles in general rather than about one paper, add it under the right heading with the date, and tell the user in one line that it was recorded. Decisions about wording go to `language.md` instead.
- When a new decision contradicts an entry, replace the entry; do not keep both.

## Content

- Interpret only what the paper records. Do not add the interpreter's own critique, limitation commentary, or doubts. Limitations and hedges the authors themselves state are reproduced as written. (2026-10-18)
- Preprints are not labelled "未经同行评审" or similar. `paper_journal` is the server name, e.g. `bioRxiv`. (2026-10-18)
- Several papers by default become separate, independent articles. Articles do not refer to each other or compare papers. (2026-10-18)
